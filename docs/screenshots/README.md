# Mnerys interface screenshots

The screenshots in this directory are development previews from 2 November 2026.

- **mnerys-workspace-desktop.png:** Chromium screenshot at 1440 × 900 of the real app running in an isolated, fresh development instance, authentication disabled and no user data.
- **mnerys-workspace-mobile.png:** same isolated app, Chromium at 390 × 844.
- **mnerys-login.png:** Chromium screenshot at 1440 × 900 of the unmodified login template and styles served by a minimal local HTTP preview server (not an authenticated session). The form is empty. This is a **standalone login UI preview**, not evidence of an end-to-end authentication test.

No conversations, model providers or credentials were fabricated for the screenshots. The header graphic in the README is an SVG *brand illustration*, not a screenshot.

## Eclipse default — current login screenshots

- **mnerys-eclipse-login-desktop.png:** actual Mnerys native preview login page, captured in headless Chromium at 1440 × 900 with the new Eclipse default, including the teal accent and starfield-depth background.
- **mnerys-eclipse-login-mobile.png:** same actual login page at 390 × 844, without credentials or personal user data.

These images are browser screenshots of the **real running application's login screen**, not mockups or images generated by an AI. They do not prove authenticated workflows or agent functionality.

## Previous terracotta screenshots (historical)

The three earlier screenshots above show the **former terracotta theme**, captured on 2 November 2026, before the Eclipse-based default was introduced. They are retained as real historical screenshots, **not** claims of the current default appearance. The application now defaults to the original Eclipse palette and starfield-depth effect. Optional original Odysseus presets and saved custom themes remain unchanged.
