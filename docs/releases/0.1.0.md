# Mnerys v0.1.0 — First public development release

Mnerys is an independent, self-hosted AI workspace built from a preserved Odysseus code snapshot and developed under its own project identity.

This release establishes a **development baseline**, not a stable API or the finished Agent Core/Gateway architecture.

## Highlights

- **Mnerys identity:** new brand, geometric M identity and Eclipse visual theme, with legacy and optional theme presets retained.
- **AI workspace:** existing chat, agent-tool interactions, document handling, skill and MCP integration foundations inherited from Odysseus and adapted incrementally.
- **Persistence:** SQLite remains the default. PostgreSQL 17 is supported as an optional primary-database backend, with an explicit migration procedure and validation checks. Auxiliary stores may remain separate.
- **Deployment foundations:** native Python/Uvicorn preview with guarded validation, backup and rollback support; Docker Compose remains an alternative installation path.
- **Documentation and provenance:** Mnerys roadmap and technical architecture docs, organized historical Odysseus archive, licensing/attribution preservation and project security requirements.

## What is not included yet

- The globally installable Mnerys CLI (`mnerys`), a standalone Mnerys TUI, and the independently factored Python Agent Core/Gateway are **planned**, not shipped in this baseline.
- The inherited agent runtime and Web interface remain under architectural modernization. Do not assume all integrations or third-party installations are production-hardened.
- Version 0.x APIs and internal interfaces may change. Migrations must be deliberate and must preserve existing data.
